# Metric calculation rules

All values are computed in `src/lib/activity/metrics.ts` from the normalized activity.
Internal units: metres, seconds, m/s, seconds-per-km. Formatting (km/mi, ft) happens only at display time.
Values the user types in (title, distance, calories, location) are stored as *overrides* and never modify the source data.

| Metric | Rule |
| --- | --- |
| Distance | Override → device-recorded cumulative distance (TCX `DistanceMeters`, FIT `distance`, used when ≥ 80 % of points have it) → sum of haversine distances between consecutive GPS points (mean Earth radius 6 371 008.8 m) → file summary. |
| Elapsed time | Override → last timestamp − first timestamp → FIT `totalElapsedTime`. |
| Moving time | Override → sum of intervals between consecutive timestamped points whose speed is ≥ 0.5 m/s (≈ 33:20 min/km) → device timer time (TCX lap `TotalTimeSeconds`, FIT `totalTimerTime`) → elapsed time. |
| Average pace | moving time ÷ distance (s/km; ×1.609344 for /mi). Average speed = distance ÷ moving time. |
| Max speed | Highest average speed over any rolling window of ≥ 10 s (suppresses single-point GPS spikes). |
| Fastest split | Fastest complete 1 km (or 1 mi) split. |
| Splits | Every 1 km / 1 mi; the time at each boundary is linearly interpolated between the two points around it. A trailing split shorter than 50 m is dropped. |
| Elevation gain / loss | Elevations smoothed with a centred 5-point moving average, then accumulated with 2 m hysteresis (a climb only counts once it exceeds 2 m from the last reference point). Falls back to FIT `totalAscent/totalDescent`. |
| Min / max elevation | Raw min / max of elevation samples. |
| Heart rate | Time-weighted mean (each sample weighted by the time to the next sample, capped at 30 s); max = highest sample. Falls back to the file summary. |
| Cadence | Time-weighted mean of non-zero samples. GPX/TCX/FIT store running cadence per leg (strides/min); for running/walking/hiking it is doubled to **steps per minute**. |
| Calories | Only from the file (TCX laps, FIT session) or a user override — never estimated. |

Unavailable metrics are reported with a reason (e.g. "The file has no timestamps") and shown as "–", never invented.

Ground-truth fixtures (`tests/fixtures`, generated by `scripts/make-fixtures.mjs`): a 5 000 m straight track at 3 m/s with a 60 s stop and a 0 → 50 → 0 m elevation profile, in GPX, TCX and FIT, plus files with missing timestamps, missing elevation, malformed XML, a planned route, an empty track and a mislabelled extension.
